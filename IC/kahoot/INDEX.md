# Cuestionarios semanales · Incidentes de Ciberseguridad

Cada miércoles cerramos con 10–15 minutos de preguntas sobre lo practicado. **No necesitas una cuenta de Kahoot:** se prevé usar el juego de preguntas propio que está desarrollándose con Codex en el ordenador del profesor.

> **Estado:** la aplicación local todavía no se ha identificado ni integrado en este repositorio. El enlace de juego aparecerá aquí solo después de publicar y verificar esa aplicación; no hay una partida operativa en esta página por ahora.

## Integración con el juego desarrollado mediante Codex

El formato de preguntas debe permitir tema, fecha, enunciado, cuatro opciones, respuesta correcta y explicación. **No publicaremos respuestas correctas en la web del alumnado** cuando el juego se use para evaluar. La integración se realizará cuando esté disponible la ruta del código de Codex o exista una rama/repo accesible; no sustituiremos su trabajo por una aplicación paralela.
