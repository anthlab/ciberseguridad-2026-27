# Gestión de Incidentes — curso 2026-2027

## Práctica 1: registro y clasificación de una alerta
Vamos a aplicar un procedimiento de respuesta ante un supuesto ficticio del portal SOC XEST.

**Situación:** aparecen cinco fallos de autenticación seguidos de un acceso correcto desde la misma dirección de laboratorio. Los registros son sintéticos.

1. Abrid el caso `XEST-INC-001` con fecha, analista, fuente y descripción.
2. Redactad dos hipótesis distintas y especificad las evidencias necesarias para confirmarlas o descartarlas.
3. Valorad impacto, urgencia y prioridad con una justificación.
4. Proponed una contención reversible y especificad qué autorizaciones necesitaríais.
5. Elaborad una cronología y un informe final breve.

**Entrega:** `registro-incidente.md`, `cronologia.md` e `informe.md` en una rama del repositorio.

**Criterios de evaluación:** evidencias y trazabilidad 35 %, clasificación 30 %, respuesta propuesta 25 %, comunicación 10 %.

No utilicéis datos reales ni registros con identificadores personales. Guardad las evidencias de trabajo con fechas y referencias coherentes.
