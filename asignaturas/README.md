## Método de entrega
Trabajad en una rama identificable, documentad cada decisión, probad el resultado y abrid una pull request. No publiquéis contraseñas, datos de compañeros, capturas con información privada ni objetivos de fuera del laboratorio.

Podéis consultar el [índice de Kahoot y test](../KAHOOT-Y-TEST.md) como apoyo a las sesiones.

Cada ejercicio indica el contexto, la tarea, las evidencias que deben conservarse y los criterios con los que se revisará la entrega.
