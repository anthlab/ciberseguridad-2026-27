# Ciberseguridad CIPFP Cheste — curso 2026-2027

Este repositorio contiene una plataforma PPS anterior (marzo de 2026) y empieza su adaptación a **tres asignaturas**. El material antiguo de `modulo-1` a `modulo-6` no debe confundirse con la programación vigente: pendiente de auditoría docente.

## Asignaturas

- [Puesta en Producción Segura](asignaturas/puesta-en-produccion-segura/README.md)
- [Hacking Ético](asignaturas/hacking-etico/README.md)
- [Gestión de Incidentes](asignaturas/gestion-de-incidentes/README.md)

## Para el alumnado

1. Clona el repositorio: `git clone https://github.com/jmpicon/PPS-jmpicon.git`.
2. Lee la guía de tu asignatura antes de ejecutar comandos.
3. Crea **tu propio repositorio privado** para las entregas; no subas datos personales, claves ni soluciones ajenas.
4. Los laboratorios vulnerables únicamente deben ejecutarse en máquinas autorizadas y redes aisladas; nunca se deben exponer puertos de práctica a Internet.

**Aviso:** no ejecutes automáticamente `docker compose up` del proyecto histórico. Contiene una terminal Kali y servicios que requieren revisión y configuración de seguridad antes de distribuirse como laboratorio compartido.

El contenido actual de Drive se enlaza como fuente de referencia; los enlaces pueden requerir acceso concedido por el docente. Los solucionarios, respuestas del Kahoot y materiales exclusivos del profesor no se publican aquí.
