# CursoPPS (curso 2025-2026)

Plataforma web que usé el curso pasado en Puesta en Producción Segura: React + FastAPI, terminal Kali en el navegador y los PDF de los módulos 1 a 6 (`modulo-1/` … `modulo-6/`).

Se conserva solo como consulta. Este curso el material está en la web generada desde la raíz del repositorio (`plataforma/`).

Si alguna vez la quieres levantar: `cp .env.example .env`, define `ACCESS_CODE` y un `SECRET_KEY` aleatorio de 32 caracteres o más, y ejecuta `docker compose up -d --build` solo en una red de laboratorio. La terminal web Kali está desactivada por defecto.
